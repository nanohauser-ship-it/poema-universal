# Organismo V4.7 · Alimentación verbal

Esta versión fue construida sobre el código V4.6 real entregado por el usuario.

Cambios visibles:
- Panel “ALIMENTACIÓN VERBAL · EN DIRECTO” en la columna derecha.
- Pulso del embrión en cada tecla.
- Contracción al borrar.
- Absorción de cada palabra al cerrarla con espacio o puntuación.
- Crecimiento 3D según biomasa provisional y materia ya integrada.
- Color de las luces según Deriva, Pulso, Fractura, Espectral, Máquina o Memoria.
- Botón “ENTREGAR MATERIA” para consolidar el texto y modificar la composición.
- Los injertos pasan a formar parte de la Partitura Viva.
